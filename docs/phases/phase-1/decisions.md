- **2026-05-04 — Codegen pipeline ships, all three runners green (46/46).** First end-to-end codegen run completed. Pipeline restructured from per-file to one-shot generation: `protocol/schemas/codegen_export.cue` exposes the canonical 18 wire-format definitions as concrete fields under `CodegenRoot`, `cue def --out=jsonschema -e CodegenRoot ./protocol/schemas/` produces a single `_generated/all.json` with `$defs`, then a Python post-processing step normalizes CUE's `#Foo` keys / `%23Foo` refs to plain `Foo` (typify and ajv reject URL-encoded `$ref`s). Schema fixes required to reach 46/46: (a) moved `import "list"` to top-of-file in five schemas (CUE syntax requires it), (b) replaced `params?: {...}` / `result: {...}` with `params?: [string]: _` / `result: [string]: _` in `#Request`/`#Notification`/`#Response` because CUE exports `{...}` as `{const: {}}` (the empty-object literal — wrong), (c) dropped the `#Hunk.end_line >= start_line` cross-field constraint (JSON Schema can't express it; daemon enforces; inverted-range fixture renamed `valid_hunk_inverted_range_daemon_layer.json`), (d) `#WorktreePath` uses `\x00` instead of `\0` (Rust regex crate doesn't recognize `\0` in char classes), (e) `#FilePath` upper bound `{0,1023}` reduced to `{0,999}` (Go's RE2 rejects bounded counts ≥ 1000), (f) `negative_detail_overlength` fixture data lengthened from 248 to 257 chars (the original was within the 256-char bound and never actually triggered the violation). Forced jsonschema 0.17 (Rust) into `Draft202012` mode via feature flag and `with_draft` so `$ref` siblings (`properties`/`required`/etc.) are honored — without this, derived schemas silently inherited only the loose base via $ref and dropped their tightening constraints. `cargo-typify` 0.6.2 panics on the `allOf` + `not` patterns from `#FilePath`/`#BranchName` and on the type-narrowing `allOf` for `#LineNumber`/`#TtlSeconds`; Rust generated types are emitted as a stub explaining the situation. Phase 1 conformance does not require Rust generated types — the runner validates against JSON Schema directly — so this is deferred. Codegen verified idempotent (md5 of generated tree equal across consecutive runs). Owner: @rileydrakedesign. Closes follow-ups #12 and #13; #14 (cargo-typify) and #15 (rules_rust crate-universe) remain deferred.
