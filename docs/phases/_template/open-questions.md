# Phase N — Open Questions

Phase-scoped open questions. Append-only: once a question is answered, mark it resolved and link to the decision in [`decisions.md`](decisions.md), but do not delete it.

Cross-phase open questions live in [`../../../project-context.md` §9.4](../../../project-context.md#94-open-questions) and in [`../../RISK_REGISTER.md`](../../RISK_REGISTER.md).

---

## Format

Each entry:

```
### Q-N-001 — Short title

**Status:** open | resolved | deferred
**Raised:** YYYY-MM-DD by @handle
**Resolved:** YYYY-MM-DD by @handle (if status == resolved)
**Deferred to:** Phase M (if status == deferred)

**Question.** State the question precisely.

**Why it matters.** What downstream decision depends on the answer.

**Discussion.** Working notes. May reference RFCs, prior art, conversations.

**Resolution (if any).** Brief statement of the answer and link to the decision.
```
